Critical User Journey

Patient-facing workflow from study link to visit-ready handoff.

This page breaks the journey into phase-level steps, decision points, data captures, and stage gates. Use the phase controls to move through the flow and expand each step for implementation notes.

Privacy and Trust

Privacy copy appears before the chat asks for health details, and follow-up privacy questions are answered in context.

Accessibility

Every phase keeps text input available while progressively offering checkboxes, voice input, read-aloud, and clear confirmation buttons.

Clinical Handoff

The workflow preserves patient edits and approval before any pre-note or evaluation handoff is considered complete.
